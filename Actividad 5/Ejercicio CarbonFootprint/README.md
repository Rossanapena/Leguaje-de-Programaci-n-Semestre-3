# Actividad 5 – Java

## Descripción

Proyecto desarrollado en Java para el cálculo de huella de carbono aplicando conceptos de Programación Orientada a Objetos y principios SOLID.

## Conceptos implementados

- Abstracción
- Herencia
- Polimorfismo
- Encapsulamiento
- Modularidad
- Persistencia de datos en JSON

## Tecnologías utilizadas

- Java
- Visual Studio Code
- Git y GitHub
- JSON

## Estructura del proyecto

```text
Actividad 5
├── Bicycle.java
├── Building.java
├── Car.java
├── CarbonFootprint.java
├── FileManager.java
├── Main.java
├── data
└── evidencias
```

## Ejecución del proyecto

```bash
javac *.java
java Main
```
