# Actividad 6 – Python

## Descripción

Proyecto desarrollado en Python para el cálculo de huella de carbono aplicando conceptos de Programación Orientada a Objetos y principios SOLID.

## Conceptos implementados

- Abstracción
- Herencia
- Polimorfismo
- Modularidad
- Persistencia de datos en JSON

## Tecnologías utilizadas

- Python
- Visual Studio Code
- Git y GitHub
- JSON

## Estructura del proyecto
